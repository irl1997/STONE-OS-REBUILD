# Tema STONE para CSS Loader

La estética de STONE (basalto, una vena ámbar, tipografías Jost, Inter e IBM Plex Mono) sobre la interfaz de Steam en Game Mode.

- `css/tokens.css`: paleta y tipografías; el único sitio donde se decide un color.
- `css/controls.css`: botones, foco, conmutadores, teclado y avisos.
- `css/shell.css`: fondos, cabecera, tarjetas y Ajustes.
- `css/game.css`: página del juego y botón JUGAR.
- `css/menus.css`: menú STEAM y menú de acceso rápido.

Los nombres de clase (`gamepaddialog_Button`, etc.) los traduce CSS Loader a los de cada versión de Steam. **Una actualización de Steam puede descolocar el tema; no afecta al sistema.** Se puede desactivar en CSS Loader, sin reinstalar nada.
